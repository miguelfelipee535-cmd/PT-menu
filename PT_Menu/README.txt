PT_Menu - Roblox Studio visual demo

This is a safe Studio-side starter project, not an external cheat.
It includes a draggable red settings panel and an optional label overlay
for dummy Models in your own experience.

Setup:
1. In Roblox Studio, create a Folder named PT_Menu under ReplicatedStorage.
2. Add each .lua file as a ModuleScript with the matching name.
3. Put a LocalScript in StarterPlayerScripts with:
       local menu = require(game.ReplicatedStorage.PT_Menu.loader)
4. Tag your own dummy Models with CollectionService tag:
       PT_DemoTarget
   Each dummy should contain a Head part.

The aimbot, silent aim, and spoofer files are safe placeholders. This package
does not use exploit executors, loadstring, hooks, player-targeting cheats,
anti-cheat evasion, or trace removal.
